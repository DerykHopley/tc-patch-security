How to read this

  • Cost is tokens × Anthropic list price (cached 2026-10-06), with cache writes at 1.25× (5 min) or 2× (1 h) input. A subscription isn't billed per token, so treat this as "what it would cost on the API".
  • Wh uses the same per-token assumptions as the status line (~/.claude/statusline-energy.py). Unverified: Anthropic publishes no energy figures. Order of magnitude only.
  • Cache read usually dominates the token count but is cheap in both money and energy. Look at output tokens for the real work.
  • Active minutes cap each gap between events at 5 minutes, so lunch breaks don't count.
  • Prompts counts messages you typed (approximate). Step-ins is your own count of corrections or unblocking, logged at the end of each stage.
  • A long single-session workflow (like superpowers) shows as one row; its subagents are counted inside it.
  • Includes subagent transcripts when Claude Code stores them beside the session.
